
Für technische Entscheidungen gilt:

* Bevorzuge einfache und nachvollziehbare Lösungen.
* Vermeide unnötige Abhängigkeiten.
* Verwende keine Backend-Dienste.
* Verwende keine externen Dienste zur Speicherung.
* Speichere keine fachlichen Daten ausschließlich im React-State oder einem vergleichbaren flüchtigen UI-State.
* Behandle Importdateien grundsätzlich als nicht vertrauenswürdig.
* Implementiere destruktive Aktionen nur mit Sicherheitsabfrage.
* Sorge dafür, dass ein fehlgeschlagener Import keinen bestehenden Datenbestand beschädigt.

Liefere zusätzlich:

* Beispiel- oder Demodaten für mindestens drei Anwendungen,
* mindestens zwei Reports für eine der Anwendungen,
* eine Beispielexportdatei,
* automatisierte Tests,
* eine kurze Architekturdokumentation,
* eine Beschreibung des Datenformats,
* eine Liste bekannter Einschränkungen.
